# Reinicio completo de actividad de pruebas

Conserva usuarios y catálogos/configuración. Elimina generaciones, archivos vinculados, saldos y movimientos de tokens, compras, pagos, facturas, suscripciones locales, lotes financieros y métricas derivadas. La cancelación de suscripciones Stripe es opcional y se ejecuta antes del borrado local.
