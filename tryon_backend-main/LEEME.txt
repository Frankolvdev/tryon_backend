HOTFIX: CANCELACIÓN BÁSICA INMEDIATA

1. Descomprime estos archivos en la raíz de tryon_backend.
2. Ejecuta:

   python APLICAR_HOTFIX_CANCELACION_BASICA.py

3. Después valida:

   python -m compileall app

El script modifica solamente:
app/services/generation_module_runtime_service.py

Cambios:
- Una ejecución queued o running pasa inmediatamente a cancelled.
- Se intenta mantener la interrupción real existente de Local Docker y RunPod.
- Una excepción causada por el interrupt ya no cambia el estado a failed.
- Modal queda cancelado localmente por ahora, aunque su worker remoto todavía no se detiene.
